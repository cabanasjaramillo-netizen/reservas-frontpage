# reservas-frontpage

Página del celular del sistema de reservas de Cabañas Jaramillo, publicada con GitHub Pages:
https://cabanasjaramillo-netizen.github.io/reservas-frontpage/

Contiene solo `index.html`: la copia de `paginas/app.html` del repositorio `calendario-y-gestion-reservas`, con la dirección del motor (Apps Script) y el identificador público del inicio de sesión de Google. No contiene datos, llaves ni contraseñas. El motor solo atiende a la cuenta del dueño.

No se edita aquí: los cambios se hacen en `calendario-y-gestion-reservas` y se vuelven a copiar.
